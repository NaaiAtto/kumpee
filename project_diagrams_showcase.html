หัวข้อที่ 3: ผังงานระบบตามมาตรฐาน ISO 5807 (System Flowchart)

สไตล์ A: Standard ISO Flowchart (ผังงานมาตรฐาน ISO)

คำอธิบาย: ผังงานรูปทรงมาตรฐาน ISO 5807 รวมกิ่ง Error Handling, CORS Check และ Smart Fallback ครบถ้วน

สไตล์ B: Modern Step-Node Flowchart (ผังการ์ดมนสไตล์โมเดิร์น)

คำอธิบาย: ออกแบบผังงานด้วยโหนดการ์ดมน มีตัวเลขกำกับขั้นตอน 9 ขั้นตอน เรียงลำดับเข้าใจง่าย

1️⃣ Start: ผู้ใช้เปิดหน้าเว็บเข้าสู่ระบบ
2️⃣ User Input: พิมพ์คำถามหรือกดไมโครโฟนพูดภาษาไทย (STT)
3️⃣ Round 1 RAG: ดึงพระสูตรที่เกี่ยวข้อง 5 อันดับแรกจากคลัง 932 ระเบียน
4️⃣ Serverless Proxy: เช็ค Origin 403, เช็ค Rate Limit 15/min, แนบ Server System Prompt
5️⃣ Claude AI Call: ยิงไปหา `claude-haiku-4-5-20251001` ได้คำตอบภาษาไทย
6️⃣ Round 2 Reverse Check: นำคำตอบ AI ค้นซ้ำในคลังพระสูตร
7️⃣ Verdict Generation: ออกตราประทับมหาปเทส 4 (สอดคล้อง / ไม่พบหลักฐาน)
8️⃣ UI & Audio Output: แสดง Verdict Card, การ์ดอ้างอิงกรอบเขียว/ทอง, เสียงอ่าน TTS & อวาตาร์ขยับปาก
สไตล์ C: Fault-Tolerant Circuit Flowchart (เน้นระบบแก้ปัญหา Error)

คำอธิบาย: เน้นแสดงเส้นทางกู้คืนระบบเมื่อเกิดข้อผิดพลาด (Fault Tolerance Pathways) เพื่อยืนยันเสถียรภาพ 100%
